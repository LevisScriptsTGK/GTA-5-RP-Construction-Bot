# 🚧 GTA-5-RP-Construction-Bot

Автоматический помощник для прокачки профессии Строителя на GTA 5 RP серверах.

Забудьте о рутинном кликабельном фарме. Бот полностью эмулирует действия игрока, позволяя вам уходить в AFK (отойти от клавиатуры) и прокачивать уровень строителя в разы быстрее, без риска получить бан за макросы (благодаря продвинутой системе рандомизации задержек).
